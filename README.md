
# Field Incident Reporter

Android-based field incident reporting app with a local mock REST API.

## Overview

Field Incident Reporter is a mobile application designed to help field technicians report, track, and manage physical incidents.

## Technology Stack

### Android
- Kotlin
- Jetpack Compose
- MVVM
- Clean Architecture principles
- Kotlin Coroutines and Flow

### Backend
- Node.js
- JSON Server
- REST API
